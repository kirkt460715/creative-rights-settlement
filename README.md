# 馆藏纹样联营月结交接

授权链、套装组成和月结出款来自三套账。月结包有已签发账期和正在处理的后续事件。 数据全部为合成业务记录。文件使用 UTF-8 JSON，时间均为北京时间，货币如无单独说明均为人民币分。

## 查阅交接数据

使用 Python 3.11 标准库。在仓库根目录运行 `python3 inspect_delivery.py` 查看交接文件和行数，或在后面加文件名（含 `.json`）查看该文件的第一条记录。这个入口仅供查阅交接资料。

## 数据约定

- `works.json` 馆藏纹样登记号，展示名可重复。
- `licenses.json` 从有效窗开始日含起、到结束日为止（不含结束日）。known 为登记入账时间。相同 license 用当时已知最新版。撤回版结束日是撤回生效日。父合同给子合同限定权利和适用范围，当组成指定子合同并且整条路径有效时，父、子合同上的权利人各有独立应分份额，以同一组成净实收为基数。rate_bps 为相对该基数的万分比。
- `composition.json` 独立标价用于套装分摊。按履约日选择同一商品最近一版的完整组成。license 为空为自产包装。
- `bills.json` gross 为未扣店铺优惠的实际订单金额，discount、tax、shipping 为需扣减总额。
- `refunds.json` 退款同时列实际付款退回额和分成所用净退回额。component 为空时是整行订单退款，否则只对应指定组件。
- `disputes.json` 复议范围及时间。底数复议会影响该行所有适用份额，只有相关结论生效后才继续依新事实处理。
- `issued.json` 财务已签历史付款事实，可能受先前记录错误影响，不能重新解释为从未支付。
- `close_periods.json` 账期左端包含，右端不含，review_cutoff 是审核可以看到的最新信息。

## 检查资料

运行 `python3 -m unittest discover -s tests -v`。检查会读取当前交接文件，核对该业务所需的关键原始证据是否齐备。
